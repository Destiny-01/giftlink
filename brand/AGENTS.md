# Brand workstream rules

Read `IMPLEMENTATION.md` and `approved/GUIDELINES.md` before using brand artifacts.

The approved logo is the ORIGINAL round-01 Claim Register geometry, exported in `approved/logos/`. The sliced diagonal N introduced in round 02 was explicitly rejected. Never regenerate logos from prose, recreate them with CSS, or use exploration files as production assets. Use canonical SVGs unchanged and run `node brand/verify-assets.mjs`.

The round-02 colour/typography aesthetic is approved and captured in `approved/`. Historical drafts cannot override this package. Keep product behaviour and scope governed by `docs/PRODUCT.md`, `docs/DECISIONS.md` and the current build brief. Do not treat static mockups as implemented features.
