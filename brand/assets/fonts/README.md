# Brand font sources

Downloaded 21 September 2026 from the Google Fonts repository:

- Instrument Sans variable font: https://github.com/google/fonts/tree/main/ofl/instrumentsans
- IBM Plex Mono Regular: https://github.com/google/fonts/tree/main/ofl/ibmplexmono

Original font binaries retained, locally renamed only for stable asset paths. Each family's SIL Open Font License is included alongside the font. No modified font build is distributed. The review uses these local files and does not call a font CDN.
