# Nomine brand

The approved Nomine identity: the Claim Register mark, its palette, type and usage rules.

- [`approved/GUIDELINES.md`](approved/GUIDELINES.md): identity and usage rules.
- [`approved/index.html`](approved/index.html): visual reference.
- [`approved/logos/`](approved/logos): canonical SVG symbols, outlined lockups, avatars and favicon.
- [`approved/logo-manifest.json`](approved/logo-manifest.json): asset hashes.
- [`approved/tokens.css`](approved/tokens.css) and [`approved/tokens.json`](approved/tokens.json): colour and type tokens consumed by the frontend.
- [`assets/fonts/`](assets/fonts): Instrument Sans and IBM Plex Mono, with their OFL licenses.

Brand changes need an explicit decision (see `docs/DECISIONS.md`, D-017).
